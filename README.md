# Portfolio

Angular 21 full-stack developer portfolio with SSR, Signals, Standalone components, and deferred loading.

## Run

```bash
npm start
```

Open `http://localhost:4200`.

## Production (SSR)

```bash
npm run build
npm run serve:ssr:portfolio
```

## Customize

Edit content in `src/app/data/portfolio.data.ts` (name, links, projects, experience).
Replace `public/VinayNB_24092026.pdf` with your real resume.
